# URL Shortener

A URL shortening service built with ASP.NET Core Minimal API and .NET 8. The project allows users to create short URLs, redirect through generated short codes, inspect URL statistics, and delete shortened URLs.

The project focuses on backend development using Minimal APIs, Entity Framework Core, SQLite, DTOs, service-layer architecture, input validation, URL expiration, click tracking, and automated testing.
